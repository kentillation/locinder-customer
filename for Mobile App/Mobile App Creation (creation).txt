How to convert Vue.js project into Mobile App using Capacitor (web app wrapper)?
- On your project directory, open the Git CLI
- run "npm install @capacitor/cli@latest"
- run "npm install @capacitor/core@latest"
- run "npm install @capacitor/android@latest"
- run "npm install @capacitor/network@latest"
- run "npm install @capacitor/preferences@latest"
- run "npm install @capacitor/splash-screen@latest"
- run "npx cap init [app-name] com.example.[app-name-with-no-space]"
- run "npx cap add android" for android and "npx cap add ios" for IOS
- run "npm run build"
- fix capacitor.config.js
- run "npx cap sync [platform]"
- run "npx cap copy"
- run "npx cap open android" or "npx cap open ios" to open IDE
- create offline.html file
- run "npx cap build [platform] or you can build the APK in Android Studio for Android
